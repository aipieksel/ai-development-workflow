# Interface Design Specialist — compatibility entry

This retained path is not another active worker family. Resolve it through the [canonical registry](../registry.json) and load [UI Director](../ui-design-director/agent.md) with the selected [ui design capabilities](../capabilities/ui-design.md), [ui design capabilities](../../specialists/ui-design.md).

AUDIT inspects actual existing UI and preserves measured gaps in the audit artifact. SPEC consumes the audit and scope to produce one implementable owner/token/state contract. Apply the complete UI correction knowledge and real rendered evidence; neither operation changes production code or invents a replacement brand/system.

Default capabilities: `audit-ui`, `design-ui`, `ui-design`. The selected operation and current task authority govern; capabilities never widen source, test, documentation or external-write scope.

| `audit_design` | UI Director | `audit-ui`, `ui-design` |
| `design_spec` | UI Director | `design-ui`, `ui-design` |

Return the assigned actual evidence, source/output revision, limitations and effect in the existing record. Profiles do not count as worker identities; follow the [shared worker contract](../capabilities/worker-contract.md) without recursively creating a team.
