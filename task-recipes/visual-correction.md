# Repair precise visual feedback

Apply itemized corrections to the current approved artifact and verify the requested delta together with protected properties.

Read [the shared portable recipe contract](README.md) first. Use the authoritative expansion and recommended lenses in [catalog.json](catalog.json); adapt them to the current task and actual tools.

## Convert feedback into bounded changes

Continue the current artifact and unresolved findings. Record each requested correction, exact region/property, evidence, required delta and approved properties to retain. A smaller heading does not authorize changed line height, tracking, wording or font family. Removing shading does not authorize replacing the widget. The latest explicit correction overrides earlier suggestions while unaffected approvals remain protected.

Find the true component/token/state owner and reproduce the issue. Distinguish a source defect from stale previews, missing fonts/assets or an incorrect installed/exported version. Capture the relevant before state; avoid reopening unrelated design choices.

## Close the loop

Implement only the reviewed corrective scope. For known small corrections, shorten the suggested expansion and reuse current planning/evidence rather than creating another full project. Compare the changed property before/after and recheck protected neighbors, relevant hover/active/theme/responsive states and interactions. If the visible result is unchanged, investigate the actual output served before claiming completion.

Close each correction only with its observable result, final artifact identity and regression evidence. Reopen only materially affected previous checks. A new critique is not permission to redesign approved work.
