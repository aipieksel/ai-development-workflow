# Rebuild from a supplied reference

Reconstruct supplied HTML, screenshots or extracted pages while preserving declared source details and validating the rendered result.

Read [the shared portable recipe contract](README.md) first. Use the authoritative expansion and recommended lenses in [catalog.json](catalog.json); adapt them to the current task and actual tools.

## Establish the target

Identify every supplied source, its role and revision: HTML/CSS/JS, screenshots, fonts, images, extraction manifests and approved companion components. Resolve conflicting sources using the latest adopted instruction. Distinguish reconstruction from authorized rebranding or creative adaptation; record protected geometry, content and behavior before changing anything.

Map requested sections to actual reusable owners. Read the relevant design-system/extraction/import skill when present; it owns its detailed format. Inventory all requested pages and meaningful states, including below-fold content. A screenshot proves only visible appearance; do not infer hidden interactions or missing assets.

## Deliver and inspect

Implement the reviewed map using the requested medium. Preserve supplied fonts, spacing, component behavior and relative assets unless the requested adaptation changes them. Compare source and output at matched viewport, theme, data and settled-font state. Exercise actual links, tabs, menus and responsive behavior where present. Use real screenshot/crop evidence; do not assign an unsupported “pixel-perfect” score.

Reconcile the full requested inventory with outputs and intentional exclusions. Open the final packaged artifact, not only an intermediate preview. Report unavailable source or runtime evidence specifically and keep affected claims unverified.
