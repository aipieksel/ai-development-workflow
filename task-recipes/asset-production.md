# Produce or edit a visual asset set

Create source-aware images, SVGs or banner variants with explicit composition constraints, distinct concepts where requested and complete output reconciliation.

Read [the shared portable recipe contract](README.md) first. Use the authoritative expansion and recommended lenses in [catalog.json](catalog.json); adapt them to the current task and actual tools.

## Select the transformation mode

Inspect each supplied image/source before editing. Distinguish faithful local editing, constrained variants and open concept exploration. Record fixed camera angle, position, scale, floor/baseline, symmetry, logo proportions, subject identity, transparency and output dimensions where specified. For constrained variants, enumerate only permitted axes; for exploration, define materially different concepts rather than changing labels on the same image.

Use the available image-generation/editing tool when it owns raster creation or editing. Preserve transparency when required. Do not substitute traced geometry, embedded raster or a screenshot for another requested format without an explicit limitation. SVG delivery must state whether it contains editable vector paths or embedded pixels.

## Inspect the actual outputs

Review every requested variant at useful scale, including composition, feet/cropping, edges, logos, blur and artifacts. Compare any “unchanged” protected regions against the source. Verify file dimensions and alpha/format when local files are genuinely available; do not download tool-generated images just to create redundant deliverables or hashes.

Use an expected output manifest for multi-product or multi-variant work. Reconcile exact counts and product identities, distinguish reviewed from merely generated results, and provide the requested artifacts through the actual tool/delivery mechanism. Do not claim precise geometry or vector fidelity from visual plausibility alone.
