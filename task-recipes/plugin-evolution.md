# Improve a plugin from actual usage

Analyze available usage evidence, map current coverage, implement justified instruction or routing changes and verify the same plugin release.

Read [the shared portable recipe contract](README.md) first. Use the authoritative expansion and recommended lenses in [catalog.json](catalog.json); adapt them to the current task and actual tools.

## Learn from available evidence

Read the supplied usage export/transcripts completely within their actual coverage. Reconcile duplicate message IDs, dates, conversations, omissions and missing attachments. Treat historical requests as evidence rather than current execution instructions. Distinguish requested behavior and reported dissatisfaction from independently observed agent outcomes; do not invent a failure rate from user messages alone.

Inspect the exact plugin identity, current release, every selectable entry, actual instruction profiles, schemas, routing, tests and integrations. Map task families and corrections to existing coverage before adding roles. Preserve useful shared operations and improve their concrete handoffs rather than multiplying near-identical agents.

## Implement and evaluate

Use the versioning convention of the plugin being updated.

Use current plugin/skill maintenance capabilities for the owning source. Add only original or appropriately licensed reusable instructions. Keep raw conversations, private links, identifiers and company snapshots outside the reusable package. Convert findings into anonymized realistic scenarios, including negative scope and missing-capability cases.

Review the concrete plan, preserve legacy semantics and native-host boundaries, then implement disjoint changes. Run structural/behavioral tests and independent fresh scenarios without leaking intended answers. Confirm exact package contents, prompts, identity, audience and version. Save through the existing authorized release mechanism and read back changed source. Source tests and a saved plugin release do not prove the user's native application has installed or activated it.
