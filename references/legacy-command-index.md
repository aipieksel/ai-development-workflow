# Legacy command lookup

The complete retained command catalogue is maintained in [the advanced reference](advanced-reference.md#all-41-g-commands), including all 41 G handlers, exact launcher names, aliases, phases, write scopes, delegation and prerequisites. Public usage starts with [Auto, Plan, Build, Review or Loop](public-modes.md).

This pointer avoids maintaining a second partial command table. The individual command files remain authoritative for their exact assignment; the generated [workflow index](workflow-index.md) is an additional source-derived lookup.
